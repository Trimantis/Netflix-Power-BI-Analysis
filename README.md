Netflix Content Analysis using Power BI 🎬📊
📌 Overview
This project analyzes Netflix’s content catalog using Power BI to uncover trends in:

Genre distribution 🎭
Movie vs. TV show growth over time 📅
Top content-producing countries 🌍
The dataset was cleaned and visualized to provide actionable insights.

📊 Key Insights
📌 Drama & Comedy are the most common genres.
📌 TV shows have grown significantly in recent years.
📌 The U.S., India, and the U.K. dominate content production.

🛠 Tools & Technologies
Power BI – Data visualization & dashboarding
SQL – Data cleaning & querying
Excel – Initial data preprocessing
